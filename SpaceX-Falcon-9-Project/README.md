# SpaceX Falcon 9 Project

## Project Overview

This project analyzes SpaceX Falcon 9 launch data to understand launch outcomes and predict whether a Falcon 9 first-stage booster will successfully land.

The project follows an end-to-end Data Science workflow, including data collection, web scraping, data wrangling, exploratory data analysis, SQL analysis, interactive visualization, dashboard development, and machine learning.

## Objectives

- Collect and prepare SpaceX launch data
- Explore launch and payload characteristics
- Analyze launch outcomes using SQL
- Visualize launch sites using interactive maps
- Build an interactive dashboard using Plotly Dash
- Develop machine learning models to predict landing success
- Identify factors associated with successful Falcon 9 landings

## Project Workflow

### 1. Data Collection
SpaceX launch data was collected using APIs and web scraping techniques.

### 2. Data Wrangling
The collected data was cleaned, transformed, and prepared for analysis.

### 3. Exploratory Data Analysis
Statistical analysis and visualizations were used to identify patterns and relationships in the launch data.

### 4. SQL Analysis
SQL queries were used to analyze launch sites, payloads, landing outcomes, and mission results.

### 5. Interactive Visual Analytics
Folium was used to create an interactive map showing SpaceX launch sites and geographical relationships.

### 6. Interactive Dashboard
A Plotly Dash dashboard was developed to explore launch success rates and payload relationships interactively.

### 7. Machine Learning
Classification models were developed to predict Falcon 9 landing success.
